# Project agent memory

This file is the project's committed home for project-intrinsic agent knowledge: build, test, release, architecture, and sharp-edge notes that should travel with the code.

- Hard rule: the app never writes under FM_HOME or `~/.claude`, except `lib/wake.js` appending one line per order to `<home>/state/ship-deck-inbox.status` (append-only, `--no-wake`; add no other FM_HOME write); its other writes are `~/.ship-deck/` (orders, sessions.json, `attachments/`; see `lib/attachments.js` and the README Attachments section). `lib/fleet.js`, `lib/sessions.js` discovery and `lib/activity.js` (first mate transcript tail) only read. The only commands allowed are `tmux list-windows`, `tmux capture-pane` and `<home>/bin/fm-send.sh <window-from-meta> <msg>` (all in `lib/actions.js` / `lib/fleet.js`, execFile, fixed argv; live config sends only `lib/config.js` allow-listed `/effort`/`/model`), plus the startup-only browser opener in `server.js` `openBrowser` (own URL, `--no-open`); add no others (the captain name is parsed from git config files, not `git`). Every other captain action is an order kind in `lib/orders.js`, documented in the README contract table. Tests fingerprint the home and inject the executor - never run fm-send in tests.
- `createServer` defaults `ordersDir`/`claudeDir` to the real `~/.ship-deck` and `~/.claude`: tests and manual runs must pass temp dirs (`--orders-dir`, `--claude-dir`). Home auto-detection (`lib/home.js`) takes an inherited `FM_HOME` first, and firstmate shells export the real one: run manual checks with `env -u FM_HOME` or an explicit `--home`. Anything that spawns the server (start.sh tests, manual runs) passes `--no-open`/`SHIP_DECK_NO_OPEN=1`, or it opens a real browser tab. In a browser against the real home, never click Send/Apply live (they reach real workers). Browser checks: run against a scratch `--orders-dir`; `chrome-devtools-axi` needs `CHROME_DEVTOOLS_AXI_MCP_PATH` pinned to a cached chrome-devtools-mcp 1.6.0 and writes screenshots only to temp dirs (copy them into `docs/`); its `eval` takes one expression (wrap statements in an IIFE). For the Activity feed, install `test/fixtures/transcript/firstmate.jsonl` (replace `__HOME__`/`__SESSION__`) under a scratch `--claude-dir`. Screenshots for `docs/` show the home path and first-run paths: pin them to neutral text (e.g. `~/firstmate`) before capturing; never commit a real name or path.
- POST routes must keep the Host/Origin/`X-Ship-Deck` guards in `server.js`; clients send crew ids or library keys, never paths or tmux targets.
- Zero dependencies, no build step: `node server.js` (or `bin/ship-deck.js`, the npx entry) to run, `npm test` (node:test) to test. UI copy is plain language (`public/labels.js`, README "Words on screen"); API fields, order kinds and files keep firstmate's names. See README.md for flags and data sources.
- Never test against the real fleet home by modifying files; copy `test/fixtures/home` (fabricated data only, never real fleet records) to a temp dir and point `--home` at it.
- Real fleet data drifts: status lines may carry a timestamp prefix or `[key=...]`, `project=` paths differ in case, and status logs contain stray shell output. Keep parsers loose and add a fixture case when a new shape appears.
