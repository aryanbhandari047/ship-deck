Ship Deck shows a firstmate fleet, but it did not find a firstmate home. It looked here:

    A firstmate home is the folder with AGENTS.md, bin/fm-spawn.sh and state/. Stop this server (Ctrl+C) and start it again with one of:

    npx ship-deck --home /path/to/firstmate
FM_HOME=/path/to/firstmate npx ship-deck
cd /path/to/firstmate && npx ship-deck   # run from inside the home

    Or keep your home at ~/firstmate and Ship Deck finds it on its own. This page reloads when the server comes back.
